Starter board

A two-layer starting point set up for kicad-part-importer and kicad-fab-package.

  • Text variables: BOARD_NAME, COMPANY, DESIGNER, REVISION, RELEASE_DATE (Schematic Setup > Text Variables). The title blocks use them.
  • Symbol field templates: MPN, Manufacturer, LCSC, Voltage, Tolerance, Type, TempCo.
  • Fab rules: JLCPCB 2-layer (<project>.kicad_dru). Swap in another file from the template repository's rules/ folder.
  • Plot settings: absolute origin, no X2 or netlist attributes, no Protel extensions.
  • Net classes: Default (0.2 mm) and Power (0.4 mm; nets +*, GND*, VBAT*, VBUS*, VIN*).
  • Drawing sheet: drawing-sheet.kicad_wks with a placeholder logo. Replace it in the Drawing Sheet Editor.

Put each board in its own folder next to the part library, e.g. hw/<board>/ beside hw/lib/.
