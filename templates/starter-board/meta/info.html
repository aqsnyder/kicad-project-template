Starter board

A two-layer starting point set up for kicad-part-importer and kicad-fab-package.

  • Text variables: BOARD_NAME, PROJECT_NAME, COMPANY, DESIGNER, REVIEWER, REVISION, RELEASE_DATE (Schematic Setup > Text Variables). The title blocks and the front pages use them.
  • Front pages: Cover, Architecture, Mechanical and Revision History, drawn by frontpages.py from frontpages.json. After creating a project from this template, run it on the project folder so the pages carry the new name.
  • Symbol field templates: MPN, Manufacturer, LCSC, Voltage, Tolerance, Type, TempCo.
  • Fab rules: JLCPCB 2-layer (<project>.kicad_dru). Swap in another file from the template repository's rules/ folder.
  • Plot settings: absolute origin, no X2 or netlist attributes, no Protel extensions.
  • Net classes: Default (0.2 mm), Power (0.4 mm; nets +*, VBAT*, VBUS*, VIN*) and GND (0.4 mm; nets GND*), plus RF_50R, Debug, UART, Bus, Clock, Analog and USB, which only colour their nets. The Architecture page has the key.
  • Colour theme: Altium_Theme, in the template repository's themes/ folder. Install it with theme.py install, then choose it in Preferences > Schematic Editor > Colors and PCB Editor > Colors.
  • Drawing sheet: drawing-sheet.kicad_wks with a placeholder logo. titleblock.py --logo PNG puts yours in.

Put each board in its own folder next to the part library, e.g. hw/<board>/ beside hw/lib/.
